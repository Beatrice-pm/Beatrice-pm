## Hi, I'm Beatrice 👋

I'm a Product Manager running **BEC Studio** — a solo studio where I build individual-first products end to end, from idea to ship.

### 🔭 Currently building

**Bragio** — an accomplishment-tracking app for individual professionals. The idea: capturing a work win should take under 15 seconds, so people actually have the evidence when it's time for a performance review, a promo packet, or a resume refresh. Right now it's in the validation phase — PRD written, competitive landscape mapped, market sized.

### 🧭 How I work

- **PRD and market read before a line of code.** Every product gets a written problem statement, MVP scope, and competitive/market analysis before build starts.
- **Decisions come with a "why," not just a "what."** I keep the rationale next to the decision so context doesn't get lost as a project moves.
- **Individual-first, not team/org tooling** — for v1, I build bottoms-up for a single user, not a buyer committee.
- **Underserved over saturated.** I look for categories everyone agrees are useful but nobody's made effortless yet — that gap is usually the real product.
- **Lean MVPs.** Prove the core loop works (people actually use it, week over week) before adding integrations, AI, or monetization.
